🥩 MeatShop Mini-App

MeatShop Mini-App is a lightweight, test-ready web application designed to showcase the core functionality of an online butcher shop. It allows users to browse meat products, view details, and simulate placing orders — all within a clean and responsive interface.



✨ Features

🛒 Product Catalog – View a list of available meat cuts (beef, pork, chicken, lamb, etc.) with images, prices, and weight options.



🔍 Product Details – Click on any item to see a full description, origin, and storage recommendations.



📦 Order Simulation – Add items to a cart and proceed through a mock checkout flow (no real payment processing).



📱 Responsive Design – Works smoothly on desktop, tablet, and mobile devices.



⚡ Fast \& Lightweight – Built as a mini-app for quick loading and easy integration.



🧪 Test Purpose

This mini-app is intended for:



UI/UX testing – Evaluate layout, navigation, and user interactions.



Functional testing – Validate cart logic, product rendering, and responsive behavior.



Developer demonstrations – Showcase front-end skills or integration capabilities.
